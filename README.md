# Korean Photo Booth

A bilingual (English / Mongolian) Korean-style photo booth kiosk built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Allow camera access when prompted. Camera access requires `localhost` or HTTPS.

## Production build

```bash
npm run build
npm run preview
```

## Features

- Touch-first photo booth flow with English and Mongolian UI
- Five photo-strip layouts with 4, 6, or 8 shots
- Browser camera preview, mirrored capture, countdown, and retake flow
- Color themes and natural, soft, warm, and monochrome filters
- Composited photo strip PNG download
- Keyboard focus styling and reduced-motion support
